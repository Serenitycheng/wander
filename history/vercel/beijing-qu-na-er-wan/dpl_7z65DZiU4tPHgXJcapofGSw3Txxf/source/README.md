# 北京去哪儿玩

一个面向小范围朋友使用的北京周末决策系统。它先收集每个人的具体出发地、兴趣、预算、体力和明确禁忌，再给出三个可解释候选；选定后生成“各自出发 → 系统汇合点 → 共同活动 → 各自返程”的完整地点顺序，不生成详细时间表。

## v1.0.0 已有内容

- Serenity 与 zzz 的独立空间和账号权限底座
- 多人分别回答、未全部回答也可由发起人继续
- 59 条首批结构化活动、10 个分类、随机探索模式
- 三候选、推荐理由、风险提示、快速对比
- 高德地址/公交/驾车/步行/骑行接口位置
- DeepSeek 自由文字解析接口位置
- 本机自动保存、跨页面覆盖冲突保护
- Neon 云端数据结构、审计日志和发布版本表

## 数据边界

实时天气、营业时间、当周展演、快闪与花期没有数据时不会用模拟内容替代。自由文字发送给 DeepSeek，以及把含具体地址的行程上传到 Neon，默认关闭，只有在用户明确授权后才开启。

## 发布准备

复制 `.env.example` 中需要的配置到 Vercel 环境变量。密码只使用 scrypt 哈希，API 密钥只在服务端读取；`.env*`、本地浏览器资料和构建产物均不会进入版本库。
