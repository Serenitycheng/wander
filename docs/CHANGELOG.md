# 更新记录

## v2.0.0 - 2026-10-08

- 主产品升级为“自由探索”，提供出门、居家、学习、创作和完全随机五种模式。
- 首页改为轻入口，每轮最多三个建议，支持时间与状态选择、换一组及简短详情。
- 探索内容调整为 50 个活动，新增具体书籍、纪录片、词作、音乐、棋类、运动、手作和技术体验；23 个旧条目退出推荐池，已有收藏、记录和链接仍可读取。
- 详情增加作品与教程直达按钮，区分内容来源与地点线索；换行标题的整块区域可点击。
- 首页进一步收拢为随机开始与四个探索方向，移除空收藏/记录面板；加入柔和渐变和彩墨背景，强化页面层次与手机首屏入口。
- 参考序流与学迹增加七种预设、自定义色值和每页独立配色；按账号保存，兼容旧偏好，并保证自定义浅色下按钮文字可读。
- 将主产品样式拆为基础布局、首页、探索、内容页和配色组件，便于后续独立修改。
- 新增分类收藏、“最近想试”和简单探索记录；支持编辑、移开撤销、按账号保存与本机备份导入导出。
- 新收藏和记录独立存储，保留北京模块原有的出行数据、账号权限、Neon 云空间、高德路线与 DeepSeek 接口。
- 原北京功能移至 `/beijing`，相关组件与模型集中于 `features/beijing/`。
- 根目录统一运行命令、工作区配置和锁文件；文档集中到 `docs/`，完整恢复快照归档至 `archive/recovery-2026-09-09/`。
- 恢复快照继续按原清单校验，构建产物、依赖、密钥与本机浏览器目录加入忽略规则。

## v1.3.1 - 2026-09-02

- 修复选择具体活动类型后仍残留“随机探索”状态的问题；现在点选任何具体类型都会自动切回计划模式，并在推荐页显示本轮硬筛条件。
- 修复未参加者的历史兴趣混入本次推荐的问题；本次参与者改为可选，只有勾选账号会参与兴趣、禁忌和路线计算。
- 将“城市与摄影”和“阅读与文化”合并为“城市与文化”，旧云空间自动迁移，推荐卡优先展示具体活动名。
- 修复 DeepSeek Responses 联网工具被持续强制调用、最终没有正文的问题；允许检索完成后生成结构化结果，并扩充输出额度和诊断元数据。
- 已确认 Neon 生产空间读取与自动保存均正常返回，继续保留逐次版本与覆盖冲突保护。

## v1.3.0 - 2026-09-02

- 修正不同活动类型仍反复推荐相同候选的问题：计划模式严格命中已选类别，多类别优先分别入选，并去除重复候选。
- 新增三选一实时发现接口：DeepSeek 搜索公开网页，高德匹配具体活动地点或店铺，结果卡直接显示官方、小红书与高德来源。
- DeepSeek 联网调用改为官方支持的 Responses API 参数，关闭默认深度思考、限制输出并补充上游错误记录。
- “本周发生”不再只显示笼统的 `Failed to fetch`，会显示超时、鉴权或上游返回等具体原因。
- 接入 Vercel Marketplace Neon：Serenity/zzz 独立云空间、自动版本历史、跨设备同步和乐观锁覆盖冲突保护。
- 启用 Serenity/zzz 登录保护；Serenity 可访问两人的空间，zzz 只能访问自己的空间。

## v1.2.1 - 2026-09-02

- 修正首页“本周适配”状态卡：高德和 DeepSeek 均已配置时显示“实时服务已接入”。
- 天气状态改为“高德天气已配置”，云端数据库未开启时明确显示“云同步未开启”。

## v1.2.0 - 2026-09-02

- 接通高德天气、地址定位、多人交通对比、系统汇合点和真实地图路线；地图密钥通过站内安全代理使用。
- 选定候选后，分别展示每个人的公交、驾车、骑行和步行预计耗时与距离；路线涉及市郊铁路时单独标记，班次仍要求官方确认。
- “本周发生”支持 DeepSeek 联网检索，官方活动必须同时通过来源域名与未来 7 天日期校验，不合格结果不展示。
- 增加小红书公开页面线索和站内搜索入口；用户内容始终标为未核验，不作为营业时间、票务或日期依据。
- 增加检索缓存、频率限制、过期保护、失败降级，以及手机与电脑端完整适配。

## v1.1.0 - 2026-09-02

- 接通 DeepSeek Chat Completions，默认使用 `deepseek-v4-flash` 将最后补充解析为兴趣、感受、禁忌和其他约束。
- 增加逐人、逐次授权开关；只有主动勾选并点击解析时才会发送补充文字。
- DeepSeek 请求不包含姓名、账号和具体出发地址，API Key 仅由服务端环境变量读取。
- 解析结果自动合并到当前填写人的偏好中，并参与后续三个候选的规则排序。
- 增加超时、上游错误、无效 JSON 和缺少密钥的可读提示；完成正式构建与安全门禁测试。
