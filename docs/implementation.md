# 漫游：自由探索重构

依据：`product/自由探索重构修改说明.txt`。主产品正式命名为“漫游”（原暂名“自由探索”），北京去哪儿玩保留为子模块。

## 本次实现

- 首页集中为随机开始与四个探索方向；按后续界面反馈移除空收藏、空记录面板和重复页尾文案，收藏与记录保留在导航中。
- 出去走走、在家探索、学点东西、做点东西、完全随机。
- 可选时间和当前状态；每轮固定 3 个建议，混合具体内容与开放活动，支持换一组。
- 推荐优先联网发现新作品、教程和活动；90 个本地入口补足数量和开放选择。以口味分析与明确爱好为依据，书单只作辅助，保留陌生领域；未展示内容优先，刷新后沿用本机账号历史。同作品变换平台、版本或解读不视为新内容。
- 详情只保留说明、适配理由与一个很小的开始动作。
- 收藏按四类分组，可标记最近想试，不设期限或完成状态。
- 简单记录支持新增、编辑、移开并即时撤销；感受、日期、地点都可轻量填写。
- 两账号分别保存本机探索数据，支持全站统一底色、命名配色方案与备份导入导出；兼容已有数据。
- 北京功能保留问答、推荐、路线、活动库、联网检索与原云空间。
- 柔和渐变和彩墨背景、清晰的主按钮、四类轻卡片与中文衬线标题；桌面导航与手机底部导航。
- 配色参考序流与学迹的竹绿、暖棕、雾蓝、藤紫、亚麻、玫瑰、青灰；支持原生选色器和自定义色值，浅色按钮自动保证文字对比度。
- 主产品样式按基础布局、首页、探索、内容页和配色组件拆到 `features/exploration/styles/`，入口样式仅负责导入与基础重置。
