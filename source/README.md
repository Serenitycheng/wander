# 北京去哪儿玩

一个面向小范围朋友使用的北京周末决策系统。它先收集每个人的具体出发地、兴趣、预算、体力和明确禁忌，再给出三个可解释候选；选定后生成“各自出发 → 系统汇合点 → 共同活动 → 各自返程”的完整地点顺序，不生成详细时间表。

## v1.3.1 已有内容

- Serenity 与 zzz 的独立空间和账号权限底座
- 多人分别回答、未全部回答也可由发起人继续
- 59 条首批结构化活动、10 个分类、随机探索模式
- 三候选、推荐理由、风险提示、快速对比
- 高德天气、地址定位、多人交通对比、系统汇合点与真实路线地图
- 本周官方活动联网检索：来源域名校验、未来 7 天日期校验与过期保护
- 小红书公开页面线索与站内搜索入口，始终和官方事实层分开
- DeepSeek 自由文字解析：逐人逐次授权，只发送“最后补充”文字并把结果合并进偏好
- 三选一实时发现：所选活动类型严格参与筛选，DeepSeek 搜索公开网页，高德落到具体地点，并分别展示官方与小红书来源
- 联网失败时只降级到严格活动库与高德匹配，不再用泛称或虚构来源冒充实时结果
- Neon 云端自动保存：Serenity/zzz 独立空间、跨设备读取、逐次版本记录与覆盖冲突保护
- 本次参与者可以选择；具体类型会自动退出随机模式，并作为推荐硬筛条件
- “城市与摄影 / 阅读与文化”统一为“城市与文化”，旧空间会自动迁移
- Serenity 可查看并编辑 zzz 空间；zzz 只能访问自己的空间

## 数据边界

实时天气、营业时间、当周展演、快闪与花期没有数据时不会用模拟内容替代。自由文字只有在当前填写人逐次勾选同意并点击解析后才会发送给 DeepSeek；实时发现只发送匿名活动类别和日期关键词。姓名、账号、具体出发地址、个人禁忌和预算不会进入 DeepSeek 请求。小红书内容只作为未核验线索。完整空间数据已按用户授权保存到本项目关联的 Neon 数据库，仅由登录后的站内服务端按账号权限读取。

## 发布准备

复制 `.env.example` 中需要的配置到 Vercel 环境变量。密码只使用 scrypt 哈希，API 密钥只在服务端读取；`.env*`、本地浏览器资料和构建产物均不会进入版本库。
