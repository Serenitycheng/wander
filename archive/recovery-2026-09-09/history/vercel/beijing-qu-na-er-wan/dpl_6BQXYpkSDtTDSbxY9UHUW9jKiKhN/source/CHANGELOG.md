# 更新记录

## v1.3.0 - 2026-09-02

- 修正不同活动类型仍反复推荐相同候选的问题：计划模式严格命中已选类别，多类别优先分别入选，并去除重复候选。
- 新增三选一实时发现接口：DeepSeek 搜索公开网页，高德匹配具体活动地点或店铺，结果卡直接显示官方、小红书与高德来源。
- DeepSeek 联网调用改为官方支持的 Responses API 参数，关闭默认深度思考、限制输出并补充上游错误记录。
- “本周发生”不再只显示笼统的 `Failed to fetch`，会显示超时、鉴权或上游返回等具体原因。
- 接入 Vercel Marketplace Neon：Serenity/zzz 独立云空间、自动版本历史、跨设备同步和乐观锁覆盖冲突保护。
- 启用 Serenity/zzz 登录保护；Serenity 可访问两人的空间，zzz 只能访问自己的空间。

## v1.2.1 - 2026-09-02

- 修正首页“本周适配”状态卡：高德和 DeepSeek 均已配置时显示“实时服务已接入”。
- 天气状态改为“高德天气已配置”，云端数据库未开启时明确显示“云同步未开启”。

## v1.2.0 - 2026-09-02

- 接通高德天气、地址定位、多人交通对比、系统汇合点和真实地图路线；地图密钥通过站内安全代理使用。
- 选定候选后，分别展示每个人的公交、驾车、骑行和步行预计耗时与距离；路线涉及市郊铁路时单独标记，班次仍要求官方确认。
- “本周发生”支持 DeepSeek 联网检索，官方活动必须同时通过来源域名与未来 7 天日期校验，不合格结果不展示。
- 增加小红书公开页面线索和站内搜索入口；用户内容始终标为未核验，不作为营业时间、票务或日期依据。
- 增加检索缓存、频率限制、过期保护、失败降级，以及手机与电脑端完整适配。

## v1.1.0 - 2026-09-02

- 接通 DeepSeek Chat Completions，默认使用 `deepseek-v4-flash` 将最后补充解析为兴趣、感受、禁忌和其他约束。
- 增加逐人、逐次授权开关；只有主动勾选并点击解析时才会发送补充文字。
- DeepSeek 请求不包含姓名、账号和具体出发地址，API Key 仅由服务端环境变量读取。
- 解析结果自动合并到当前填写人的偏好中，并参与后续三个候选的规则排序。
- 增加超时、上游错误、无效 JSON 和缺少密钥的可读提示；完成正式构建与安全门禁测试。

## v1.0.0 - 2026-08-31

- 完成“首页 → 多人问答 → 三项推荐 → 纵向路线 → 保存方案”的可操作流程。
- 支持 Serenity、zzz 两个独立预览空间；Serenity 可切换查看 zzz 空间。
- 录入 59 条首批结构化活动，覆盖 10 个分类；保留 PDF 中 94+ 方向的扩展位置。
- 实现普通推荐、惊喜推荐、明确禁忌优先排除、换一组三个、候选对比。
- 实现本机自动保存与跨标签页覆盖冲突检测。
- 完成高德地址与路线服务端接口、登录会话与两账号密码哈希验证底座。
- 完成 Neon 数据表结构与 Vercel 环境变量模板。
- DeepSeek 自由文字发送、含具体地址的云端同步保持关闭，等待用户明确授权。
- 通过 TypeScript、ESLint、Next.js 正式构建与桌面/移动端浏览器验证。
